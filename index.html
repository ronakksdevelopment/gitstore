Disclaimer & terms
what gitstore is, and isn't, responsible for

gitstore is a directory, not a host. Every listing you see is a JSON file submitted by a member of the public and merged into this repo as a pull request — gitstore does not write, review, execute, or vet the content of any linked app beyond the automated schema/format checks run on submission.

Clicking Install or Open in browser takes you directly to a URL supplied by the submitter, hosted entirely outside gitstore's control. Use the same judgment you would with any link on the internet before installing something.

Submitters are required to confirm, before their pull request is opened, that they own or have the right to list the app, that it is real and working, and that it isn't malware, stolen work, or illegal content. That confirmation is self-reported — it is not independently verified by gitstore.

Every submission is reviewed publicly as a pull request under the submitter's own GitHub username before it is merged. If you spot a listing that's broken, misleading, or harmful, please report it — reports open a public GitHub issue so anyone can follow the outcome.

This project is provided as-is, MIT licensed, with no warranty. Anyone can fork the repo and run their own copy under their own rules.

Connect GitHub
no server involved — your token stays on this device
gitstore has no backend. To submit an app, you connect a GitHub fine-grained personal access token — it's stored only in this browser's local storage and used to call GitHub's API directly from your device. It never passes through any server of ours.
how to create one
1. Go to github.com/settings/personal-access-tokens/new
2. Under Repository access, choose Only select repositories → pick this repo (gitstore)
3. Under Permissions → Repository permissions, set Contents and Pull requests to Read and write
4. Generate the token and copy it — GitHub only shows it once
